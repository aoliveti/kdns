# Security Policy

## Reporting Security Issues

KDNS is an open-source educational and experimental DNS server project created to explore high-performance Go, zero-allocation radix trees, and DNS protocol implementations.

If you discover a security vulnerability or potential denial-of-service issue in KDNS, please report it responsibly:

- **Preferred Method**: Open a [Private Security Advisory](https://github.com/aoliveti/kdns/security/advisories/new) directly on GitHub.
- **Alternative Method**: Contact the maintainer directly via GitHub profile.

Please do not open public issues on GitHub for undisclosed security vulnerabilities.

## Supported Versions

Only the latest release and the current `main` branch receive bug and security fixes.
